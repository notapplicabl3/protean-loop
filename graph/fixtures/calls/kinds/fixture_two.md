# fixture_two

**This is a fixture, not a kind of work.** The `delegate`-class half of the loadable pair: the same
file on the same terms as `fixture_one.md`, under the other class, so a test can read back that a
kind's class is the sub-mapping it sits in rather than anything the block or the prefix says.

It names no work and instructs nobody — what a kind is for is build A.2's (§ Out of scope). Nothing
reads this text; the loader checks only that it exists, that it resolves by realpath inside
`seats/kinds/`, and that editing it moves `seed_hashes()`.
