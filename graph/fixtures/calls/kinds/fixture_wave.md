# fixture_wave

A fixture kind's prefix, shared by every kind in `wave_kinds.yaml`.

`the build specification (not in this mirror)` § Out of scope (S-A22): **a fixture kind is not a
library kind.** These kinds name no work — which kinds exist is build A.2's and the operator holds it — so
there is nothing here for a prefix to say. What `wave_kinds.yaml`'s kinds differ in is the two
numbers a bound compares, `max_call_usd` and `timeout_seconds`, and one prefix for all of them is
what keeps that the only difference a reader has to hold.
