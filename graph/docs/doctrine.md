This is the compact reading guide to intended behavior. It adds no ruling and closes no gate. The authoritative contracts, provenance tags and amendments remain in the SPECs; the governing specification (not in this mirror) resolves their precedence. Implementation proves what exists; it does not cancel an unbuilt ruling. Current completion and approval state live in the status document (not in this mirror).

## Governing model

PROTEAN runs outside Claude Code. It supplies gating, memory, error signals, budget sensing and consolidation around Claude Code as the cortex's body. One graph serves every project; adaptation is state and memory, not project-specific wiring. The default ring is homeostasis → hippocampus → thalamus → basal ganglia → cortex → anterior cingulate. The graph's nodes may fire conditionally and ask for judgment mid-tick. Gate inhibition and homeostasis's stop remain contractual.

The cortex has two seats, director and manager. Specialized subagents form tier three; they are not a third seat. Three tiers is the ceiling. The manager alone conducts workspace changes; outer nodes escalate a needed change and may delegate only for information or a verdict. A manager acting tick assembles at most one wave, merged into one unit observation; a director tick dispatches none. Tier-three concurrency supplies fan-out.

Each outer node has three licensed call possibilities: **think** for its own judgment, **escalate** to the manager, **delegate** for specialized information. Callers use one addressee-keyed port; model invocation remains confined to `cortex/` and `oracle/`. A.2.i's trigger rules are landed and ship off — each authored node's `think_threshold` is `null` on the shipping seed — so an outer node makes none of these calls until a trigger is turned on; that is a seed setting, not a return to the old claim that only the cortex can think: A.2 owns the kinds, the prefix contents, the manager's dispatch rule and per-member write disjointness, and A.2.i the triggers. Outer-to-outer edges are allowed but exceptional; the edge set is rule only — no off-ring edge exists — and the ring stays the default path.

`claude -p` is the default body. The terminal body is for the two seats only, runtime-launched; tier three always uses print mode. Body-invariant results are the requirement; dry transport tests are not the live B32 receipt.

A runtime node's folder contains `NODE.md`, `weights.yaml`, `trace.jsonl` and `procedures/`; that is not a prescription for Python source directories. Runtime traces preserve predictions and their outcomes. Offline, deterministic, zero-call sleep is the learning writer of weights and procedures; it never rewrites node identity mid-task. Intake may seed priors through its separate first-write-only rule and must never overwrite a learner. Project-specific learning lives under project memory keyed by node; node folders hold cross-project priors.

Learning uses admissible joined evidence, existing keys, bounded steps and persistence across tasks. Seeds must be weakenable. A compiled procedure can answer a seat call through the same decoding path; it cannot fabricate a dispatch observation. No live efficacy has been established. The human review surface is the tracked diff plus `SleepReport` for the gitignored project-memory half. Sleep is hand-invoked, never scheduled.

The mailbox contains open items; unresolved items block close and silence is never assent. The operator sits above the director. Automation remains HYBRID, risk 4; the loop never merges or pushes on its own. The policy home's content may seed stores; its structure is never the design template. No graph-library adoption is authorized by the existence of the A-series.

## Held scope and limitations

A.2 owns the kinds, the prefix contents, the manager's dispatch rule and per-member write disjointness; A.2.i's triggers, think-answer carrier, per-tick delegate bound and edge rule are landed, every trigger shipped off. Of the digest's per-node intentions, nuanced homeostasis signals and reasoning about claimed versus actual results are landed as bounded thinks whose answers move no node output; richer hippocampus scoring and risk classification at the gate are deferred by ruling as named later amendments (`the build specification (not in this mirror)` E5, E4). Embedding retrieval is explicitly outside A.1, held for the recorded re-open trigger; it is not built by the existence of a think seam.

A.1.i's positive tool grant and write-denied profile do not prove a complete sandbox. For `dispatch`, network egress is neither prevented nor witnessed under current JSON envelopes; the three-tier ceiling is contractual, and a finished nested process may evade the process-group witness. `audit.wrote` is wave-level until disjoint member sets exist. Dollar ceilings bound configured caps, not exact spend. B49/B51/B52 retain these limits; `stream-json` is an unadopted decision, not a completeness guarantee.
